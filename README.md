# 🌍 Atlas de Oportunidades Laborales: Un Framework de Datos para Decodificar la Demanda de Habilidades Tecnológicas 📊
### 🎯 **¿Qué se busca con este proyecto?**

El objetivo principal es **analizar las tendencias y demandas laborales** a nivel global, con el fin de identificar las tecnologías más solicitadas, su distribución geográfica y las remuneraciones asociadas. Se desarrollará un **código en Python** que automatice la **extracción, transformación y carga (ETL)** de ofertas laborales desde diversas fuentes. Los datos consolidados se almacenarán en un archivo **.csv** y servirán como base para un **dashboard interactivo** que permitirá explorar la información de manera visual.

---

### ⚙️ **¿Cómo se llevará a cabo?**

El proyecto se desarrollará a través de los siguientes pasos:

1. **Extracción de Datos**: Se utilizarán técnicas de **Web Scraping** en portales de empleo y se consumirán **APIs** para obtener datos estructurados sobre categorías laborales, salarios y más.

2. **Transformación y Carga (ETL)**: Los datos extraídos se limpiarán, estructurarán y almacenarán en un archivo **.csv**, permitiendo su fácil análisis posterior.

3. **Visualización Interactiva**: Se construirá un **dashboard interactivo** utilizando herramientas como **Streamlit** o **Dash**. Este dashboard incluirá:

   * **Gráficos dinámicos** para visualizar las tecnologías más demandadas.
   * **Mapas de calor interactivos** para explorar oportunidades laborales por regiones.
   * **Tablas y métricas clave** que presentarán los hallazgos de manera clara y accesible.

### 🔍 **¿Por qué es importante?**

Este proyecto tiene como objetivo **modelar el ecosistema global de habilidades tecnológicas** y comprender cómo las oportunidades laborales se distribuyen geográficamente. Al contar con un dashboard interactivo, los usuarios podrán tomar decisiones informadas sobre las **habilidades más demandadas** y sus correspondientes **remuneraciones**. Además, la entrega del proyecto en **GitHub**, con código y documentación, garantizará que el proceso sea **reproducible y accesible** para futuros análisis y mejoras.

### 🎯 La Problemática: Navegando en un Mar de Incertidumbre Laboral
En un mercado tecnológico que evoluciona a una velocidad vertiginosa, profesionales y estudiantes se enfrentan a una pregunta constante: ¿Qué habilidades debo aprender para ser relevante? La información sobre qué tecnologías son las más demandadas, en qué países se concentran las mejores oportunidades y cuáles son las expectativas salariales reales está fragmentada, desactualizada y es difícil de comparar. Tomar decisiones de carrera informadas se convierte en un desafío abrumador.

## ✨ La Solución: Un [Dashboard Interactivo para la Toma de Decisiones](https://mhpw2cug5iazq4t8ctnmzf.streamlit.app)
Este proyecto nace para resolver ese problema. Hemos construido un dashboard interactivo e inteligente que no solo centraliza miles de ofertas laborales de todo el mundo, sino que las transforma en insights claros y accionables. Nuestra plataforma es una brújula para cualquier profesional que busque navegar el panorama laboral tecnológico.

#### Funcionalidades que te empoderarán con nuestra app molinera:

#### Personalización desde el Inicio
  * 👋 Bienvenida Interactiva: Al entrar, la aplicación te invita a seleccionar tus habilidades de una lista curada. Esta personalización es la clave para todo lo que sigue.

  * 🚀 Feed de Recomendaciones a tu Medida: Basado en tu perfil, el dashboard te presenta de inmediato las ofertas de trabajo más relevantes, priorizando las que mejor coinciden con tus capacidades.

#### Análisis Profundo y Visual
  * 🌏 Análisis Geográfico: Con un mapa interactivo y gráficos dinámicos, puedes explorar dónde se concentran las oportunidades, comparando la demanda entre países y regiones específicas.

 * 📈 Tendencias del Mercado: Descubre qué categorías de puestos (Data Science, DevOps, Ciberseguridad, etc.) son las más demandadas y analiza la distribución de salarios para cada una,         identificando nichos de alta remuneración.

  * 🎯 Demanda vs. Salario: Un gráfico de dispersión único te permite visualizar qué habilidades se encuentran en el "punto dulce": alta demanda y alta compensación.

#### Exploración Sin Límites
  * 🔍 Buscador Inteligente: ¿Buscas algo específico? Usa el buscador interactivo para filtrar ofertas por puesto, empresa o tecnología en tiempo real.

  * 🔧 Filtros Globales Avanzados: Toma el control total de los datos. Filtra por múltiples países, categorías de puesto, plataformas de origen (LinkedIn, Adzuna, etc.) y el tipo de extracción de datos (API o Web Scraping).

  * 💵 Conversor de Moneda y Periodo: Adapta la visualización de salarios a tu moneda local (PEN o USD) y al periodo que prefieras (mensual o anual) con un solo clic.
  
#### Más Allá de la Búsqueda: Desarrollo Profesional
  * 🎓 Conexión con el Aprendizaje: Cada oferta de trabajo no es solo una oportunidad, ¡es un plan de estudio! Hemos implementado un algoritmo que identifica las habilidades clave en cada título de puesto y te proporciona enlaces directos para que puedas aprender o reforzar esas capacidades.
  * 🤖 Asistentes con IA (Integración con Google Gemini): La aplicación integra módulos de IA para ofrecerte un Asesor de Perfil y un Generador de Rutas de Aprendizaje, llevando la planificación de tu carrera al siguiente nivel.
